# 🔑 ApertureSafe v1.0 (Локальный крипто-менеджер паролей)

**ApertureSafe** — это легковесный, полностью автономный менеджер паролей и учетных записей, разработанный на чистой Java (Swing). Программа не использует внешние сервера или облачные базы данных, обеспечивая 100% конфиденциальность информации. Все сохраненные данные шифруются локально на жестком диске.

## 🛠️ Основные возможности

* **Надежная криптозащита (XOR)** — база данных хранится на диске в зашифрованном бинарном виде (`aperture_vault.db`). При попытке открыть файл обычным текстовым редактором злоумышленник увидит лишь нечитаемый байт-код.
* **Мастер-пароль** — доступ к таблице записей открывается только после ввода секретного ключа при старте приложения. Ввод неверного ключа приводит к математическому разрушению структуры данных при дешифровке.
* **Встроенный генератор паролей** — автоматическое создание криптостойких комбинаций длиной 12 символов, включающих спецсимволы, цифры и разный регистр.
* **Строгий интерфейс** — компактная и интуитивно понятная графическая таблица в темных тонах для быстрого менеджмента данных.

## 📦 Инструкция по установке и тестированию

1. Скачайте исходный файл `ApertureSafe.java` или собранный исполняемый архив `ApertureSafe.jar`.
2. Запустите приложение и задайте свой **Мастер-Пароль** в стартовом окне.
3. Заполните поля (Сайт, Логин, Пароль) или воспользуйтесь генератором, после чего нажмите кнопку **"СОХРАНИТЬ ЗАПИСЬ"**.
4. Проверьте скрытность данных: откройте сгенерированный в папке программы файл `aperture_vault.db` с помощью стандартного Блокнота Windows. Там будет полная цифровая каша.

## ⚙️ Компиляция и сборка из исходников

Сборка автономного исполняемого пакета выполняется штатными средствами Java Development Kit (JDK):

* Компиляция исходного кода:
  ```bash
  javac ApertureSafe.java
  ```
* Упаковка в переносимый кликабельный JAR-архив:
  ```bash
  jar cfe ApertureSafe.jar ApertureSafe *.class
  ```
